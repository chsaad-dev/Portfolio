02

SpendWise — Offline Expense Tracker

SpendWise is a modern, offline-first Android expense tracking application built with Kotlin, Jetpack Compose, and Material 3. It follows MVVM architecture, uses Room for local data persistence, and provides a clean fintech-style interface for managing budgets and generating PDF reports locally. Read my [SpendWise offline-first expense tracker design article](/blog/spendwise-case-study) for more details.

⚡ Problem Solved: Most expense trackers sync sensitive financial data to external servers, raising privacy concerns. SpendWise eliminates this problem by keeping all records strictly on the user's local device, ensuring zero data exposure, and providing category budget tracking without internet dependencies.

FindCircle — Lost & Found Community App

FindCircle is a community-driven lost & found mobile app that connects people who have lost personal belongings with those who have found them, using real-time location mapping, smart image-based matching, and instant push notifications.

⚡ Problem Solved: Every day, countless people lose valuable items with no centralized way to search for them. FindCircle solves this by creating a dedicated, geo-aware platform where users can instantly post lost or found items with photos, precise locations, and category tags.
